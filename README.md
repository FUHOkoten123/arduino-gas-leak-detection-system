# Arduino-based Gas Leak Detection and Warning System

## Overview
This project is a gas leak detection and warning system using Arduino Uno, MQ-2 gas sensor, HC-05 Bluetooth module, buzzer, servo motor and fan control.

## Features
- Detect gas concentration using MQ-2 sensor
- Trigger buzzer warning when gas level exceeds threshold
- Control fan to reduce gas concentration
- Use servo motor for mechanical response
- Send data/status through HC-05 Bluetooth
- Support monitoring and warning in real time

## Hardware Components
- Arduino Uno
- MQ-2 Gas Sensor
- HC-05 Bluetooth Module
- Buzzer
- Servo Motor
- Fan
- Jumper wires and breadboard

## Technologies
- Arduino C/C++
- Arduino IDE
- Fritzing
- Bluetooth communication
